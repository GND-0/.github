# GND-0/.github

Org-wide community files for **[GND_0 VLSI Club, IIIT Dharwad](https://github.com/GND-0)**.

Files here apply automatically to **every repository in the org** that doesn't have its own copy:

| File | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The public landing page at github.com/GND-0 |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | How we treat each other, plus reporting and enforcement |
| [`COMMUNITY_RULES.md`](COMMUNITY_RULES.md) | Practical rules: channels, PDK/NDA, academic integrity, Git hygiene |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Workflow, commit style, review and quality bar |
| [`GOVERNANCE.md`](GOVERNANCE.md) | Roles, teams, decision process, annual handover |
| [`MEMBERSHIP.md`](MEMBERSHIP.md) | How to join, levels and badges |
| [`SECURITY.md`](SECURITY.md) / [`SUPPORT.md`](SUPPORT.md) | Vulnerabilities and leaked secrets / where to get help |
| [`learning/ROADMAP.md`](learning/ROADMAP.md) | The VLSI learning roadmap |
| [`docs/`](docs/) | Repository standards, maintainers list, events playbook |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Issue forms (bug, feature, learning, membership, repo request, event) |
| [`.github/DISCUSSION_TEMPLATE/`](.github/DISCUSSION_TEMPLATE/) | Forms for org Discussions categories |
| [`workflow-templates/`](workflow-templates/) | "RTL CI" starter workflow offered in every repo's Actions tab |
| [`labels.yml`](labels.yml) | Standard label set |

Changes to these files follow the [decision process](GOVERNANCE.md#how-decisions-are-made). Open a pull request.
