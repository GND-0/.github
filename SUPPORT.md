### Asking a good technical question
1. **Title:** specific, e.g. *"Verilator: `%Warning-LATCH` on case statement in FSM"*, not *"help pls"*
2. **Context:** what you're building, which tool and version, which OS
3. **Minimal example:** the smallest code that shows the problem, in a ```` ```verilog ```` block
4. **What you expected vs what happened:** exact error text, plus a waveform screenshot if relevant
5. **What you tried already**

When you get an answer, **mark it as the answer** so it helps the next person.
